# filler-killer — project notes for Claude

## Delivering Mac app builds to Dave

If the artifact contains a `.dmg` (Developer ID secrets configured in CI),
installation is: download, open the DMG, drag to Applications — send that,
not a command block. For ad-hoc builds (zip artifact), EVERY time a new
build is announced, include the complete install command block — never just
a link or an artifact name. The block (artifact name is
`FillerKiller-b<run#>`, download from the Actions run page first):

```bash
pkill -x FillerKiller 2>/dev/null || true
cd ~/Downloads
rm -rf FillerKiller.app FillerKiller-app.zip README-INSTALL.txt
unzip -o "$(ls -t FillerKiller-b*.zip | head -1)" && rm -f FillerKiller-b*.zip
unzip -o FillerKiller-app.zip
xattr -dr com.apple.quarantine FillerKiller.app
open FillerKiller.app
```

Other lessons from working with Dave's terminal:
- zsh interactive comments are OFF: never put `#` comments on command lines
  meant for copy-paste.
- His shell sometimes has a broken PATH from stuck multi-line pastes; prefer
  absolute paths (/usr/bin/curl) in diagnostic one-liners.
- Repeated artifact downloads used to collide as "(2).zip" — artifact names
  now include the CI run number; keep it that way.
- The menu footer shows the installed version+build (e.g. v0.7.0 (b20)); ask
  for it when debugging field reports, plus Settings → Advanced →
  Copy Diagnostics for the engine event log.
- Field lesson (b20): newer macOS on-device speech recognition can deliver
  partials forever without ever sending isFinal OR a silence error — anything
  counting only finalized segments counts nothing. Fixed by the stability
  commit (PartialStabilizer, Swift + Python); don't remove it.

## Architecture pointers

- Python prototype (src/fillerkiller/) is the reference implementation and
  cross-language test oracle; fixtures/ golden files are generated by
  tools/gen_golden.py and consumed by both pytest and Swift GoldenTests.
- Mac app: macapp/ (FillerKillerKit = pure Swift, Linux-testable;
  FillerKillerMacKit = GRDB persistence, mac-only; app shell via XcodeGen
  project.yml — .xcodeproj and Info.plist/entitlements are generated).
- Full v2 plan: /root/.claude/plans/i-would-like-to-enchanted-cat.md
  (session-local); milestones M0-M3 done, M4 = HUD, M5 = Retro,
  M6 = GranolaSync, M7 = ship.
